# PokéNav GBA — by FlashCore

Guia offline da Geração III, convertido a partir do PokéNav GBA v3.4 original.

**Abrir:** https://flashcore-nexus.github.io/pokenav-gba/

## Instalar no celular

1. Abra o endereço acima e aguarde **Pacote offline verificado**.
2. iPhone: Safari → Compartilhar → Adicionar à Tela de Início.
3. Android: Chrome → Instalar aplicativo / Adicionar à tela inicial.
4. Abra pelo novo ícone e confira novamente o estado offline antes de desconectar.

No Windows, instale pelo Chrome ou Edge.

## Seus dados e backups

Times, ataques, níveis, PC e jornada ficam somente no navegador. Não há login, sincronização ou backend. Para migrar do HTML antigo, exporte o JSON em Ajustes no navegador/perfil original e importe em Ajustes no novo aplicativo. Dados de file:// não são transferidos automaticamente para HTTPS.

Guarde backups JSON fora do navegador. Uma atualização de recursos estáticos não apaga os dados pessoais. Limpar dados do site ou do perfil pode apagá-los.

## Conteúdo

386 espécies, 354 golpes GBA, sprites locais, cinco equipes, oito caixas por jogo, 17 tipos, guia de batalha e as 43 etapas originais de FireRed/LeafGreen. As cinco versões GBA permanecem disponíveis; o guia de Hoenn não foi ampliado.

O Guia da Jornada 2.0 preserva as 43 etapas e checklists, com orientações de acesso, encontros de FireRed, itens e dicas em seções expansíveis. Clicar num Pokémon abre sua ficha e permite retornar à etapa anterior. As ilustrações esquemáticas foram removidas.

Em **Ajustes → Armazenamento offline**, consulte o estado e verifique os arquivos do pacote. A atualização só é oferecida após confirmar uma versão diferente e pronta para instalação; sua aplicação exige interação.

Os links de mapas externos exigem conexão. Checklists e consultas essenciais usam o pacote local. Leia [fontes e limitações](FONTES-E-LIMITACOES.md) e os avisos em [licenses](licenses/).

Se já instalou a versão anterior, abra o app conectado e escolha **Nova versão disponível — Atualizar** quando aparecer. Aguarde a indicação de pacote offline verificado antes de desconectar.

Projeto de fã não oficial. Pokémon e marcas pertencem aos respectivos titulares.
